# Mi Proyecto Web
Página web básica desarrollada en HTML para aprender el flujo de trabajo con Git, ramas independientes, Pull Requests en GitHub y docummentación con Markdown.

## Tabla de contenido

- [Instalación](#instalación)
- [Estructura](#estructura)
- [Mejoras implementadas](#mejoras-implementadas)

## Instalación

1. Clona el repositorio en tu equipo:
   ```bash
   git clone https://github.com/alejandro15795/Repositorio_Tarea01.git
   ```

2. Abre el archivo `index.html` en tu navegador web.

## Estructura
 - `index.html` : Documento principal con la estructura HTML del sitio.
 - `README.md` : Documentación del proyecto.

## Mejoras implementadas

- **Menú de navegación (`feature/menu`):** Se añadió un encabezado (`<header>`) y una barra de navegación (`<nav>`) en `index.html`.
- **Tabla de comandos Git (`feature/tabla`):** Se insertó una tabla (`<table>`) con comandos básicos de Git y su función.
- **Pie de página (`feature/footer`):** Se añadió un (`<footer>`) con redes sociales al final de la página.
